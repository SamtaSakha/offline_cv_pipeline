# BHIV CV Baseline — Face Detection & Recognition Pipeline

A bounded, offline, CPU-only computer-vision identity pipeline built for
BHIV Test 1 (see `docs/REVIEW_PACKET.md` for the full sprint record).

**Read `docs/REVIEW_PACKET.md` first.** It discloses upfront that this
repository was built with AI assistance and lists exactly what still needs
personal verification before it's an honest submission.

## What this is

```
Image → Detection → Preprocessing → Representation → Matching → IdentityResult
```

A face is detected (OpenCV Haar Cascade), cropped/normalized, turned into a
640-dimension Local Binary Pattern texture embedding, and compared against
an enrolled gallery. The output is a single, bounded JSON contract
(`identity`, `match`, `similarity`, `confidence`, ...) with **no field
capable of expressing an access decision** — see `docs/ARCHITECTURE.md`.

Runs fully offline, no GPU, no external model downloads — see
`docs/CV_MODEL_EVALUATION.md` for why.

## Repository layout

```
src/bhiv_cv/        the pipeline (8 focused modules, see docs/ARCHITECTURE.md)
tests/              37 unittest tests covering every stage + 15 failure modes
scripts/            sample-data generation, CLI enroll/identify, benchmark, runtime log
data/               generated gallery + probe images (regenerated by scripts/prepare_sample_data.py)
evidence/           real captured test/benchmark/runtime output (not hand-written)
docs/               the 8 required sprint deliverables
```

## Rebuild from clean instructions (Day 7 requirement)

```bash
cd bhiv-cv

# 1. Install dependencies (all already offline-available in this sprint's
#    environment; on a fresh machine with internet, this installs from PyPI)
pip install -r requirements.txt

# 2. Generate the sample gallery + probe images
PYTHONPATH=src python3 scripts/prepare_sample_data.py

# 3. Run the full test suite (37 tests)
PYTHONPATH=src python3 -m unittest discover -t . -s tests -v

# 4. Run the benchmark suite
PYTHONPATH=src python3 scripts/benchmark.py
PYTHONPATH=src python3 scripts/optimization_experiments.py

# 5. Generate the runtime evidence log (every probe scenario, once)
PYTHONPATH=src python3 scripts/generate_runtime_log.py

# 6. Try it yourself via the CLI
PYTHONPATH=src python3 scripts/enroll.py \
    --image data/gallery/candidate_001/sample_01_clean.png \
    --identity candidate_001 --gallery /tmp/gallery.json
PYTHONPATH=src python3 scripts/identify.py \
    --image data/probes/probe_known_candidate_001_clean.png \
    --gallery /tmp/gallery.json
```

## Minimal Python usage

```python
from bhiv_cv import CVPipeline

pipeline = CVPipeline()
pipeline.enroll("enrollment_photo.jpg", "candidate_001")
result = pipeline.identify("live_capture.jpg")
print(result.to_json())
```

## Interactive Web UI (Streamlit)

You can launch a visual, interactive dashboard to test probes against your gallery. The UI uses a clean, two-column layout to show the uploaded image alongside the real-time identity analysis matching the strict JSON contract.

```bash
# Ensure streamlit is installed
pip install streamlit

# Launch the visual dashboard
PYTHONPATH=src python3 -m streamlit run scripts/streamlit_app.py
```

## The one rule that matters most

This module never decides access. It reports identity and confidence;
what happens next is entirely a downstream (HIAS) decision. This is
enforced structurally (the contract schema has no field for it) and by
regression test
(`tests/test_pipeline_failures.py::test_low_confidence_never_becomes_a_match_even_with_lenient_thresholds`).
